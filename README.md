# SwimRocket Team Harness

Ассистенты SwimRocket для команды (Z-Code / Claude Code).

## Установка: скачай архив из списка ниже, распакуй, дважды кликни install.command

| Архив | Для кого |
|---|---|
| sr-harness.zip | Репутация: отзывы, мониторинг, автоответы |
| sr-content-day.zip | Контент-день: посты, комментарии, рассылки |
| sr-content-plan.zip | Контент-план: месячный цикл, отчёты, Директ |
| sr-design.zip | Дизайн: форматы макетов, тиражные афиши, брифы |
| sr-copywriter.zip | Копирайтер: SEO-статьи блога, серии, редактура |

## Обновление
Двойной клик update.command внутри установленного скилла — подтянет свежую версию отсюда.
